# PRAHARI — AI-Based Predictive Personnel Stress & Welfare Monitoring System

**Smart India Hackathon 2026 — Problem Statement SIH26186**

PRAHARI (प्रहरी — "Guardian") is a welfare-first, non-punitive multimodal AI system designed to estimate a person's Personnel Stress Index (PSI) by combining wearable physiological signals, facial-video behavioral cues, sleep and activity information, duty/operational workload, voluntary psychometric check-ins, and personal historical baselines.

## ⚠️ Important Disclaimer

PRAHARI is a **research/prototype decision-support system**. It does NOT diagnose mental illness or replace qualified medical or psychological assessment. Stress estimates are probabilistic signals intended to support early welfare intervention. Facial analysis provides behavioral stress-cue estimation and should be interpreted together with other signals.
